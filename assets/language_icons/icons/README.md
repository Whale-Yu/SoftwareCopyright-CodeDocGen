# 语言图标文件说明

将语言图标文件放到此目录，文件名需要与 `core/language_config.py` 中的 `LANGUAGE_ICONS` 配置一致。

## 图标文件列表

需要添加以下图标文件（建议尺寸：48x48 或 64x64 PNG格式）：

| 文件名 | 语言 | 说明 |
|--------|------|------|
| `python.png` | Python | 蟒蛇图标 |
| `java.png` | Java | 咖啡图标 |
| `go.png` | Go | Go语言图标 |
| `php.png` | PHP | PHP图标 |
| `csharp.png` | C# | C#图标 |
| `ruby.png` | Ruby | Ruby图标 |
| `javascript.png` | JavaScript | JS图标 |
| `typescript.png` | TypeScript | TS图标 |
| `vue.png` | Vue | Vue图标 |
| `html.png` | HTML | HTML图标 |
| `css.png` | CSS | CSS图标 |
| `scss.png` | SCSS | SCSS图标 |
| `c.png` | C | C语言图标 |
| `cpp.png` | C++ | C++图标 |
| `swift.png` | Swift | Swift图标 |
| `kotlin.png` | Kotlin | Kotlin图标 |
| `objc.png` | Objective-C | OC图标 |
| `dart.png` | Dart | Dart图标 |
| `rust.png` | Rust | Rust图标 |
| `sql.png` | SQL | SQL图标 |
| `shell.png` | Shell | Shell图标 |
| `default.png` | 其他 | 默认文件图标 |

## 图标配置

图标尺寸配置在 `core/language_config.py` 中：
- `ICON_WIDTH = 24`
- `ICON_HEIGHT = 24`

## 图标资源建议

可以从以下网站获取语言图标：
- devicon.dev (https://devicon.dev/)
- simpleicons.org (https://simpleicons.org/)
- GitHub 官方图标集
