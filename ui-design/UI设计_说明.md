# SC-CodeDocGen UI设计说明

## 设计目标

SC-CodeDocGen 采用现代桌面工具风格设计，整体布局参考：

- GitHub Desktop
- JetBrains Toolbox
- Cursor
- VSCode Welcome Page

设计原则：

- 单页面完成全部操作
- 减少配置学习成本
- 文件扫描结果可视化
- 适配软著申请业务流程
- 统计 → 配置 → 生成 三步完成

***
